Evaluator material. Give readers only the numbered prompts selected for the trial and the common corpus pins from [S33](dreaming-retrieval-20261118.md#source-snapshot). Keep this file, grader notes, earlier answers and evaluation transcripts outside both readers' searches.

## Questions

- **Q01** How would you split an osu! session between the two hosts, including optional inputs, return audio and authority to go public?
- **Q02** Which revision supplies measurements, Agent control, and the desktop client? What can the detached combination establish about main?
- **Q03** A teammate attributes the old hosted #19 Prepare 409 to MediaMTX. What causal claim can you sign, what changed, and which failure should stay on record?
- **Q04** Chat stops when keyboard focus leaves visible Studio. Which comparison exercises the actual window system, what changed, and when should reads cease?
- **Q05** Stop returns 202 during a held Start. When may the operator claim release, and what if another client has already prepared a new session?
- **Q06** Ingress bytes rise and the encoded timeline advances. Which counterexamples distinguish a moving but delayed source from a frozen one, and whose gate detects them?
- **Q07** The normal generated OBS run completed. Which render and output measurements matter, and what conclusion can you draw about the hardware target?
- **Q08** Someone proposes another isolated Xorg run because NVENC probing worked. What happened last time, what released the resources, and what can safely be checked off-host?
- **Q09** Does hearing real Twitch speech once settle speech during a broadcast? Which earlier failure and later success constrain another trial?
- **Q10** Do the matched replay samples establish gameplay p99 or physical A/V phase? What observation would discriminate, and when would it remain unknown?
- **Q11** Before adding another control server, GUI framework or capture backend, what implementation, rejected alternatives and acceptance criteria would you inspect?
- **Q12** In an already approved active project shell, how do you avoid repeated startup and reuse the appropriate device-free controller check?
- **Q13** After #19 is squash-merged and #20 retargeted, how would you determine which memory claims to revisit and preserve the old red job?
- **Q14** Studio lost an Apply reply. Which owner and observation let it decide whether to issue a new edit or persist a layout?
