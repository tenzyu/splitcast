## Failures and cleanup

The first physical recording Start lost its response while production was waiting for source readiness. Stop released both sessions. A second attempt collected authenticated OBS geometry and MediaMTX observations. All three sources progressed, and the text source initialized at 230×45, but KMS produced a 1364×766 game input against the 1364×768 selection. The source now permits the observed two-pixel trim per game dimension. The camera keeps exact dimensions. The same two hosts then confirmed Running using the corrected binary.

The first privileged isolated Xorg attempt opened the virtual QXL device before initializing NVIDIA. The kernel stack at Stop showed `modeset_lock` via `drm_atomic_get_plane_state`, `drm_client_modeset_commit`, and `drm_release`. The exact Xorg task remained in state D after the service Stop timed out and SIGKILL became pending. The second and third attempts restricted devices to NVIDIA and reached the virtual-terminal wait without a usable display. After Stop, both entered state D waiting on `console_lock` in `vt_ioctl`. All three service Stops timed out and all three processes still showed pending SIGKILL. Their private diagnostic display directories were retained pending release. [Signal comparison and unprivileged NVIDIA diagnosis](pr16-obs.md)

The operator later authorized a normal reboot. `systemctl --check-inhibitors=yes reboot` returned 0 after reporting two logind timeouts. The boot ID remained unchanged and PID 1 entered state D. The operator then reset the VM through its management plane. A new boot ID confirmed restart. The three Xorg tasks, their system service cgroups and the private runtime directories were absent. The active system matched the pre-reset system and was now also the booted system. Production SSH, logind and the Nix daemon responded, and NVML reported the RTX 4060 Ti. Private checkpoint files preserve the pre- and post-reset observations. The hardware OBS trial remains blocked.

Both media Agents and their scoped user services stopped. The capture wrapper was removed. The independent playback samples and private on-disk recording were deleted after deriving the receipts. The trial access token was revoked and validation returned HTTP 401. The public Twitch archives remain visible under the operator's channel settings. No runtime Nix gate or autostart target was enabled.
