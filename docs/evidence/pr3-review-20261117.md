## Contract, ownership, risks and rollback

The oracle owns source processes/feeder threads, observations and private
receipts; the actual Agent still owns production workers. Unexpected fixture
failure or cleanup failure keeps the case red. Fault/Stop exceptions begin at
explicit boundaries, not retroactively. The Rust change affects child stderr,
not authority, cancellation, output policy or public APIs; no new crate, unsafe
code, async task or deployment capability is added. The tradeoff is less raw
production logging instead of an unreviewed inherited diagnostic channel.
