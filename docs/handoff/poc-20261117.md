## Resume with the smallest missing input

1. Obtain the selected channel and an existing appropriate OAuth configuration
   **path**, or the supported local output of an existing receiver. Never request
   token values in chat, search browser/keyring stores without permission, or
   infer the channel from repository ownership. Do not ask for WSS/Helix grants
   again. No usable token means scope is unverified, not rejected by Twitch.
2. Prefer an existing receiver. With the actual inputs selected, implement only
   the missing bounded event admission to existing synthesis. Distinguish mock
   tests from a real `channel.chat.message` v1 receipt. Keep credentials and
   message contents out of public logs. Own and close only trial connections
   and subscriptions. Do not alter unrelated subscriptions.
3. Prove real Twitch reception to production VOICEVOX synthesis first. Do not
   substitute another fixed-text probe or manual message for that result.
4. Only then resolve capture playback execution. The
   [narrow request](../evidence/poc-convergence-20261117.md#narrow-capture-playback-execution-request)
   specifies existing `systemd-run`, `pw-play` and `systemctl`, scoped existing-key
   SSH, an explicit playback node, at most two seconds of PCM, a 10-second unit
   budget plus three seconds stop grace, resource limits and cleanup checks.
   This request is **not granted** by read-only SSH or by publication approval.
5. Resolve acquisition independently before integration. GSR and its KMS helper
   are absent from surveyed profiles/wrappers/cache. The inspected NixOS module
   supplies a root-owned `cap_sys_admin+ep` helper, but enabling/installing it is
   not permitted. DRM-node access alone is insufficient. Existing portal services
   and OBS PipeWire plugins are alternative candidates, not an accepted fallback.
   `pw-record` exists as an unimplemented raw microphone alternative to the cached
   FFmpeg without Pulse input. See the
   [dependency facts](../evidence/poc-convergence-20261117.md#exact-capture-dependencies).
6. Establish the same official-game workload and eligible all-frame observation
   route. Obtain Baseline before proposing performance limits. Measure short
   matched OFF/ON/OFF trials only after acquisition is usable. Include decoded
   media freshness and clock uncertainty. Do not derive p99 from slow-frame logs
   or subtract unrelated host clocks to claim end-to-end latency.
